===== Root METS file metadata section (element fileSec)
The CSIP does not make use of the METS fileSec element mandatory, but it is strongly recommended. In CITS 3D HM the use of the METS fileSec element at the package level becomes mandatory, such as to reference the METS files within each representation and to reference the file groups containing Paradata Documentation, Authentication Documentation and Other Documentation.
